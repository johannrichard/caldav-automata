# rule-file-helper

Installable skill scaffold for helping users author CalDAV Automata rule files.

It is designed to:
- turn natural-language intent into valid `(rule ...)` blocks,
- support both calendar-event and scheduling-inbox flows,
- explain filters/actions (`calendar`, `subject`, `note`, `organizer`, dates, and invite actions),
- keep output concise and copy/paste ready.
